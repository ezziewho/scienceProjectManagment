A full-stack web application with a MySQL database. Uses React.js for the frontend and Node.js for the backend. The app supports the process of applying for scientific project funding as well as project execution management. It combines elements of a corporate project management tool with modules dedicated to grant-funded research– such as a budget module. The user interface was built with Bootstrap, TablerIcons, and CSS styling. The application was tested with Artillery (load testing) and Jest (unit/integration testing).
